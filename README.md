# Infinity Furniture — concept redesign

A concept redesign of [infinityfurniture.ca](https://infinityfurniture.ca) by STOHRX: a photo-led home page and a full shop of every piece in the store.

- `index.html` — home: the rooms, the collections, fabric picker, showroom, review and visit card
- `shop.html` — all 650 products with departments, search, sorting and a quick look
- Enquiries let the customer choose how to hear back: a call, an email or WhatsApp

Static HTML, CSS and JavaScript with no build step. Product data and photographs come from the store's own catalogue (read 2026-11-12). The enquiry form opens the visitor's email or WhatsApp; it is not connected to a form backend yet.
